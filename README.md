TaskFlow
TaskFlow - это простое веб-приложение для управление пользователями и задачами. Проект реализован на Java,
с использованием Spring Boot, Spring Data JPA, Spring Security, Hibernate и MySQL.

*Приложение позволяет:
-Управление пользователями (создание, обновление, удаление, просмотр)
-Авторизация и аутентификация пользователей
-В дальнейшем ланируется добавление управления задачами для пользователей

*Технологии
Java 21
Spring Boot
Spring Data/Hibernate
MySQL
Maven
JWT (планируется добавть в дальнейшем)

*Функционал текущей версии
-Регистрация нового пользователя с валидацией данных 
-Получение пользователя по ID, имени или email
-Получение списка всех пользователей
-Обновление информации о пользователе (имя и email)
-Удаление пользователя

*Планы на развитие проекта
-Добавление модулей для управления задачами, включая создание, удаление, редактирование задач.
-Реализовать связи пользователей и задач (каждый пользователь может иметь несколько задач)
-Добавление статусов задач, приоритетов и сроков выполнения
-Внедрение уведомлений о просроченных задач 
-Поддержка JWT-аутентификации и ролей для безопасности
